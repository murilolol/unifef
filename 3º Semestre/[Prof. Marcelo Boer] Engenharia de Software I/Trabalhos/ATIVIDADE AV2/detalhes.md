# Trabalho — Atividade AV2: Documentação do Projeto do Aplicativo

> **Professor:** Marcelo Tadeu Boer
> **Disciplina:** Engenharia de Software I (3º Semestre)
> **Prazo de entrega:** 16/06/2026 às 01:30
> **Pontuação máxima:** 4 pontos

## Descrição da atividade

"Postar a documentação do projeto do aplicativo criado." Entrega final da disciplina: cada grupo deve produzir a documentação completa do projeto de um aplicativo escolhido, seguindo rigorosamente a estrutura do template oficial do professor.

## Estrutura obrigatória (modelo de entrega do professor)

Conforme [`ModeloEntregaAv2Final.docx`](../../Aulas/Casos%20de%20Uso%2C%20Atores%20e%20Ferramenta%20Astah%20UML/ModeloEntregaAv2Final.docx) (ver detalhamento completo na [Aula: Casos de Uso, Atores e Ferramenta Astah UML](../../Aulas/Casos%20de%20Uso%2C%20Atores%20e%20Ferramenta%20Astah%20UML/detalhes.md#modelo-de-entrega-da-av2)):

1. **Análise Orientada a Objetos – Fase de Análise:** Descrição do Contexto; Lista de Atores (Diagrama de Atores); Quadro de Descrição dos Atores; Diagrama de Contexto Geral (por ator); Lista de Casos de Uso; Lista de Mensagens; Principais Diagramas de Caso de Uso com Quadro de descrição (Realizar Login, Cadastrar, Listar, Carregar, Alterar, Excluir).
2. **Diagrama de Classes (Fase de Análise).**

A capa segue o padrão institucional: Fundação Educacional de Fernandópolis / Centro Universitário de Fernandópolis, nome dos alunos, nome do aplicativo, e a assinatura do orientador **Prof. Esp. Marcelo Tadeu Boer**.

## Resolução

A resolução em [`documentacao_projeto_medsync.md`](./documentacao_projeto_medsync.md) aplica o template ao **MedSync**, sistema web/mobile de gestão de clínicas médicas (agendamento e Prontuário Eletrônico do Paciente), cobrindo introdução e escopo, Engenharia de Requisitos (RF/RNF), atores, casos de uso e Diagrama de Classes da fase de análise. O script complementar [`script_ddl_medsync.sql`](./script_ddl_medsync.sql) traz o DDL do modelo de dados derivado dessa modelagem.

## Arquivos entregues

- [`script_ddl_medsync.sql`](./script_ddl_medsync.sql) — script DDL do banco de dados do projeto.
