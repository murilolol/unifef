Aula 02 - Criando um projeto web

## Resumo do material

Apresentação detalhada da instalação e configuração do ecossistema de desenvolvimento Java Web com OpenJDK 17 Temurin, Apache Tomcat 9 e Apache NetBeans 24. Introdução aos fundamentos da arquitetura de software monolítica e à estruturação do padrão MVC dividido em pacotes específicos: View, Filter, Controller, Model, DAO e Utils. Demonstração prática da criação de um projeto Web Application com Apache Ant, adição de bibliotecas essenciais como o driver JDBC do PostgreSQL e JSTL, organização de pacotes e ciclo de execução de páginas JSP no servidor.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
