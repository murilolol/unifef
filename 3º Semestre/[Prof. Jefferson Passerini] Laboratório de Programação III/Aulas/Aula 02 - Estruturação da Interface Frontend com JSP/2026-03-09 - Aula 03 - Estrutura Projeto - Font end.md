## Resumo do material

O professor Jefferson Passerini apresentou a organização modular da camada View em uma aplicação Java Web utilizando JavaServer Pages (JSP) e a biblioteca de tags JSTL. Foi demonstrada a divisão da interface em componentes reutilizáveis de cabeçalho, menu e rodapé por meio da ação jsp:include na página inicial. Além disso, foram integradas bibliotecas front-end como jQuery, jQuery Mask, Bootstrap, DataTables e SweetAlert2, acompanhadas de scripts para formatação dinâmica e validação de CPF e CNPJ.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
