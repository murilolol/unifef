Aula 04 - Conexão com o Banco de Dados

## Resumo do material

Nesta aula aprendemos a criar e estruturar um banco de dados PostgreSQL utilizando o pgAdmin, definindo a tabela de usuários e executando scripts SQL de inicialização. Em seguida, implementamos o padrão de projeto Singleton na classe SingleConnection para gerenciar uma única instância de conexão JDBC. Por fim, construímos um FilterAutenticacao para interceptar requisições web, gerenciando o ciclo de vida da conexão e praticando a depuração no NetBeans.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
