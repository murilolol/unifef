Aula 05 - Criando o Listar Usuario

## Resumo do material

Nesta aula foi iniciada a implementação do CRUD de usuários aplicando o padrão arquitetural MVC em uma aplicação Java Web com banco de dados PostgreSQL. O professor detalhou a construção da classe de modelo Usuario com encapsulamento completo e a padronização das operações de persistência por meio da interface GenericDAO e da classe UsuarioDAO via JDBC. Na camada de controle, foi implementado o Servlet UsuarioListar para interceptar as requisições HTTP e despachar os dados para a camada de visualização. Por fim, desenvolveu-se a página JSP usuario.jsp com tags JSTL (core e fmt) e integração ao plugin jQuery DataTables para fornecer paginação, pesquisa e ordenação na interface.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
