## Resumo do material

Nesta aula prática, foi realizada a criação e estruturação do banco de dados relacional PostgreSQL bdaplcurso por meio do pgAdmin e versionado via script SQL no NetBeans. Em seguida, implementou-se o padrão de projeto criacional Singleton na classe SingleConnection para gerenciar uma conexão JDBC única com controle transacional manual. Por fim, desenvolveu-se o FilterAutenticacao para interceptar requisições HTTP na aplicação web, integrando o ciclo de vida da conexão com técnicas de depuração e acessibilidade.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
