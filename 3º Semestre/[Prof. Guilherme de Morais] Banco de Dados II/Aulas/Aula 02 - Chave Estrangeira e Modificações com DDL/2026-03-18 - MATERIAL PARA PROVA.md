## Resumo do material

A aula apresentou os fundamentos de integridade referencial através do uso de chaves estrangeiras (FOREIGN KEY) em modelos relacionais. O professor demonstrou a definição de restrições tanto na criação das tabelas via CREATE TABLE quanto posteriormente com ALTER TABLE ADD CONSTRAINT. Foram também detalhadas operações de evolução de esquema como adição, exclusão e renomeação de colunas, constraints e tabelas.

Explicação completa, diagramas, código e exercícios em [detalhes.md](detalhes.md).
