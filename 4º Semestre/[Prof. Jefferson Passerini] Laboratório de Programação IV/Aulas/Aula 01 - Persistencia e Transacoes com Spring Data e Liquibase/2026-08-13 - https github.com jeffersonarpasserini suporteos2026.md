Este material aborda a construcao incremental de uma API Spring Boot em Java 21, cobrindo desde a configuracao do ambiente e modelagem de dominio puro ate a persistencia relacional com PostgreSQL, controle de esquema versionado com Liquibase, e gerenciamento de transacoes e repositories com Spring Data JPA.
