## 2. Conceitos-Chave e Terminologia Fundamental

Com base no material fornecido, o conceito mais fundamental e explícito para esta disciplina é o uso de **GitHub** e **Controle de Versão**.

*   **GitHub:** Uma plataforma de hospedagem de código-fonte e arquivos com controle de versão usando Git. É amplamente utilizada para desenvolvimento de software colaborativo e gerenciamento de projetos. Na disciplina, o GitHub (`jeffersonarpasserini/suporteos2026`) serve como o hub central para materiais, exercícios e, possivelmente, submissão de trabalhos.
*   **Repositório (Repository):** No contexto do GitHub, é o diretório principal de um projeto, contendo todos os arquivos (código, documentação, etc.), o histórico completo de revisões e as ferramentas para colaboração. O repositório `suporteos2026` é o ponto de partida para todo o conteúdo da disciplina.
*   **Controle de Versão (Version Control):** Um sistema que registra as mudanças feitas em um arquivo ou conjunto de arquivos ao longo do tempo, permitindo que você recupere versões específicas mais tarde. **Git** é o sistema de controle de versão distribuído subjacente ao GitHub, essencial para gerenciar o código-fonte, rastrear alterações, reverter para versões anteriores e facilitar o trabalho em equipe.
*   **Clonar (Clone):** Ação de baixar uma cópia completa de um repositório remoto (do GitHub) para o seu computador local.
*   **Commit:** Um "instantâneo" das alterações feitas no código em um determinado momento, com uma mensagem descritiva.
*   **Push:** Ação de enviar os commits locais para o repositório remoto no GitHub.
*   **Pull:** Ação de baixar as últimas alterações do repositório remoto para o seu repositório local.
*   **Branch (Ramificação):** Uma linha independente de desenvolvimento dentro de um repositório, permitindo que desenvolvedores trabalhem em novas funcionalidades ou correções sem afetar a linha principal de código.

Outros conceitos-chave específicos da programação (como paradigmas, estruturas de dados, algoritmos, frameworks, etc.) serão detalhados dentro do próprio repositório GitHub, que é a fonte primária do conteúdo programático.
