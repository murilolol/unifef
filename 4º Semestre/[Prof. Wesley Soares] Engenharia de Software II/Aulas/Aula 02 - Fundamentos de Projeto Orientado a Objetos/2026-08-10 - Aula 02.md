## Resumo do material

A aula abordou a transicao da analise para o projeto orientado a objetos, detalhando os principios fundamentais de design OO como encapsulamento, heranca e polimorfismo. Tambem foram apresentados o metodo MoSCoW para priorizacao de requisitos e as etapas essenciais para a modelagem de sistemas robustos.
